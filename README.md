# flezzle-rs-workbook

Hands-on companion to [flezzle-rs](https://github.com/nverhaaren/flezzle-rs):
a series of projects presenting the codebase in a deliberately incomplete
state (a submodule pinned into flezzle-rs history) with a goal to implement
and supporting exposition. Built for the repo owner's active involvement in
AI-assisted development — and as a study/onboarding path into flezzle-rs.

- **[CONVENTIONS.md](CONVENTIONS.md)** — how projects, branches, submodule
  pins, and solution-checking work.
- **[ROADMAP.md](ROADMAP.md)** — task-dag of planned projects.
- **[projects/01-sample-platformer/](projects/01-sample-platformer/)** — get
  the platformer running: assemble the game app, implement player movement.
